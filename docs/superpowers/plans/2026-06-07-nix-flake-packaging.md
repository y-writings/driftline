# Nix Flake Packaging Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let Nix users build, run, and install `driftline` directly from this repository.

**Architecture:** Add a root flake that uses nixpkgs `buildGoModule` to build the existing Go CLI entrypoint at `./src/cmd/driftline`. Filter the package source to `go.mod`, `go.sum`, and `src/` so local Nix result symlinks and docs do not affect builds. Expose the derivation through package outputs and app outputs so both `nix build` and `nix run` work with default and named outputs.

**Tech Stack:** Nix flakes, nixpkgs `buildGoModule`, Go 1.26.x, existing Go module metadata.

---

## File Structure

- Create `flake.nix`: declares nixpkgs input, supported systems, filtered Go package source, `driftline` package, default package, named app, and default app.
- Create `flake.lock`: generated by Nix to pin the nixpkgs input.
- Modify `README.md`: documents Nix run/build/install commands while keeping the existing Go source build command.
- No source Go files change.
- No commits are part of this plan because the current agent instructions require commits only when explicitly requested.

### Task 1: Add Initial Flake Outputs

**Files:**
- Create: `flake.nix`

- [ ] **Step 1: Create `flake.nix` with a temporary module hash**

```nix
{
  description = "driftline CLI";

  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
  };

  outputs = { self, nixpkgs }:
    let
      systems = [
        "x86_64-linux"
        "aarch64-linux"
        "x86_64-darwin"
        "aarch64-darwin"
      ];

      forEachSystem = f:
        nixpkgs.lib.genAttrs systems (system:
          f system (import nixpkgs { inherit system; })
        );
    in
    {
      packages = forEachSystem (_system: pkgs:
        let
          driftline = pkgs.buildGoModule {
            pname = "driftline";
            version = "0.0.0";

            src = pkgs.lib.cleanSourceWith {
              src = ./.;
              filter = path: _type:
                let
                  rel = pkgs.lib.removePrefix "${toString ./.}/" (toString path);
                in
                rel == "go.mod"
                || rel == "go.sum"
                || rel == "src"
                || pkgs.lib.hasPrefix "src/" rel;
            };
            subPackages = [ "src/cmd/driftline" ];

            vendorHash = pkgs.lib.fakeHash;

            ldflags = [
              "-s"
              "-w"
            ];

            meta = {
              description = "Copy files from a GitHub Source Repository into a Target Repository";
              homepage = "https://github.com/y-writings/driftline";
              license = pkgs.lib.licenses.mit;
              mainProgram = "driftline";
            };
          };
        in
        {
          inherit driftline;
          default = driftline;
        });

      apps = forEachSystem (system: _pkgs:
        let
          driftline = {
            type = "app";
            program = "${self.packages.${system}.driftline}/bin/driftline";
          };
        in
        {
          inherit driftline;
          default = driftline;
        });
    };
}
```

- [ ] **Step 2: Run the initial build to generate the real module hash**

Run: `nix build .#driftline`

Expected: FAIL with a fixed-output hash mismatch that prints a `got: sha256-...` value for `vendorHash`.

- [ ] **Step 3: Replace the temporary hash**

In `flake.nix`, replace this line:

```nix

```

with a quoted string containing the exact `got:` value from Step 2. The final `flake.nix` must not contain `pkgs.lib.fakeHash`.

- [ ] **Step 4: Build the named package**

Expected: PASS and creates `result/bin/driftline`.

- [ ] **Step 5: Build the default package**
